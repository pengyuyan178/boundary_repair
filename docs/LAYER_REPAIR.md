实验入口 `scripts/run_layers.py` 直接复用既有 Docker 镜像租用和单向生成/官方评分流程：

```bash
python scripts/run_layers.py --launch <fresh_launch_directory> --mode census --split dev
python scripts/run_layers.py --launch <fresh_launch_directory> --mode generate --split dev --modules 111
```

启动目录必须包含 `runtime_template.json`、冻结源码 `method_snapshot/` 和对应 `source_files.sha256.json`。使用服务器既有 GPT-4.1 配置；代码不读取 `.env` 到日志。完整 test 使用 `--split test`，八种消融使用 `--modules 000` 至 `111`，每组必须建立新的输出目录并使用同一冻结源码、模型与预算。dev 验收与方案冻结完成之前不启动 test，不根据评测结果生成第二个补丁。

`scripts/audit_layers.py --batch <batch> --output <new_report.json> --layer-metrics` 统计逐层绑定、证书、实际权限和请求字符数，不读取评测答案。HTTP 服务失败保存限长脱敏原因，503、格式验证失败、未评分和正式未解决分别报告。
